# USTP

USTP is no longer maintained.

The active project is now **USTP-Secure**, which keeps the UDP/USTP transport idea but makes encryption/authentication mandatory.

Repository:
https://github.com/x1colegal/USTP-Secure

## Status
- This repository is archived in practice.
- New protocol work should happen in USTP-Secure.
- Existing code here is kept only as historical proof-of-concept material.
